<p><small>Del Python al ecosistema Java: Spring Boot, DI, REST, JPA ☕</small></p>

---

Python es genial para aprender y para producir rápido, pero en el mundo empresarial Java sigue siendo rey. Esta unidad te da un puente directo: partiendo de lo que ya sabes en Python, verás los conceptos clave de **Spring Boot** (el framework Java más usado para servicios web) y cómo se comparan con lo que ya dominas.

No es un curso completo de Java: es una guía de supervivencia para que entiendas un proyecto Spring Boot, puedas leerlo, modificarlo y crear uno básico. Si en el futuro necesitas profundizar, tendrás la base sólida.

---

## 🎯 Objetivo de la unidad

Al terminar, serás capaz de:

- Entender la sintaxis básica de **Java** comparándola con Python.
- Explicar qué es **Spring Boot** y por qué domina el backend empresarial.
- Comprender la **inyección de dependencias** (DI) y el patrón de contenedor IoC.
- Crear un API REST con **@RestController**.
- Conectar a una base de datos con **JPA** (Hibernate).
- Montar un mini-proyecto completo: API de tareas con CRUD.

## 📝 ¿Qué necesitas?

- Conocimientos de Python (lo que has visto en la UD 1).
