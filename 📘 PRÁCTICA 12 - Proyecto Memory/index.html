    📘 PRÁCTICA 12 — Proyecto Memory

    🟢 MUY FÁCIL — Sin resolver. ¡A construir el juego!

    1. Tablero 2×2

    Crea la clase MemoryJuego con tablero de 2×2 (2 parejas). Muestra el tablero.

    2. Barajar cartas

    Añade código para barajar las cartas con random.shuffle.

    3. Destapar carta

    Implementa el método destapar(idx) que marque una carta como descubierta.

    4. Servidor básico

    Crea un servidor TCP que responda "MEMORY-OK\n" cuando un cliente se conecte.

    5. Cliente básico

    Crea un cliente TCP que se conecte y muestre la respuesta del servidor.

    6. Protocolo DESTAPAR

    Añade lógica al servidor para que entienda el comando DESTAPAR <idx> y responda MOSTRAR <idx> <valor>.
